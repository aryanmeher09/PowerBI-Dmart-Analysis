# DMart Sales Analysis Dataset

##  Project Overview
This dataset is used for analyzing *DMart retail sales performance* using *Power BI*.  
The analysis focuses on understanding sales trends, customer behavior, product performance, and regional insights to support data-driven business decisions.

---

##  Dataset Description
The dataset contains transactional retail data from DMart stores, including information about sales, products, customers, and regions.

It is designed for:
- Exploratory Data Analysis (EDA)
- Business Intelligence reporting
- Power BI dashboard creation
- Beginner to intermediate data analytics practice

---

##  Columns Information
| Column Name        | Description |
|--------------------|-------------|
| Order_ID           | Unique identifier for each order |
| Order_Date         | Date when the order was placed |
| Customer_ID        | Unique customer identifier |
| Customer_Name      | Name of the customer |
| Product_Category   | Category of the product |
| Product_Name       | Name of the product |
| Quantity           | Number of units sold |
| Sales              | Total sales amount |
| Profit             | Profit earned from the sale |
| Region             | Sales region |
| Store_Type         | Type of DMart store |

(Column names may vary slightly depending on data version)
